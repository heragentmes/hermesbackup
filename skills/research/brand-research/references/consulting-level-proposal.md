# Consulting-Level Proposal Structure (McKinsey/Deloitte Style)

## When to Use
When the user wants a proposal that positions them as a media consultant (not just a social media manager). Use this structure for CEO-level deliverables.

## User Feedback Summary
> "If you want to be a media consultant for the holding, not just someone who does Instagram and website work, the proposal structure must be different."

> "Something like McKinsey, Deloitte, or PwC documents."

> "A CEO should feel they're facing a management consultant, not someone who provides social media services."

## Structure (18-22 pages)

### Page 1: Cover
- Professional title: "پروپوزال طراحی و استقرار نظام رسانه‌ای و توسعه بسترهای دیجیتال"
- Company name, period, date
- Confidentiality marking

### Page 2: Executive Summary (1 page)
- One page only, no extra words
- Answer: Why this project?

### Page 3: Current State Analysis (table)
| Domain | Current State | Improvement Opportunity |
|--------|--------------|----------------------|
| Website | Template ready but lacks content strategy | Transform into brand reference |
| Instagram | Active but no content identity | Increase trust and engagement |
| LinkedIn | Limited use | Build organizational brand |
| Telegram | News reposting | Transform into analytical media |
| Brand | Not recognized | Positioning |

### Page 4: Core Problem
- "The main issue is the lack of an integrated media system"
- Explain how website, social media, and brand operate separately
- Data mining section: analytical approach as expertise differentiator
  - Audience behavior analysis
  - Content performance analysis
  - SEO and traffic analysis
  - Competitor analysis
  - Trend forecasting

### Page 5: Project Objectives (3 goals)
1. Establish media identity
2. Complete digital infrastructure
3. Create sustainable content production process

### Page 6: Media Ecosystem Architecture (diagram)
Strategy → Website → LinkedIn → Instagram → Telegram → Lead Generation

### Pages 7-8: Phase 1 - Analysis & Design (Month 1)
| Week | Activity | Output |
|------|----------|--------|
| Week 1 | Brand analysis | Analysis report |
| Week 2 | Competitor analysis | Comparison report |
| Week 3 | Website architecture design | Sitemap |
| Week 4 | Content strategy | Strategy document |

Deliverables: Strategy document, Site architecture, Brand identity, Content calendar

### Pages 9-10: Phase 2 - Implementation (Month 2)
| Week | Activity | Output |
|------|----------|--------|
| Week 5 | Complete website | Final version |
| Week 6 | Launch LinkedIn | Active page |
| Week 7 | Content production | Initial content |
| Week 8 | Integration testing | Feedback report |

Deliverables: Complete website, LinkedIn page, Visual templates, Initial content

### Pages 11-12: Phase 3 - Development & Optimization (Month 3)
| Week | Activity | Output |
|------|----------|--------|
| Week 9 | Performance analysis | KPI dashboard |
| Week 10 | Media campaign | Campaign execution |
| Week 11 | Team training | Training documentation |
| Week 12 | Final report | 3-month report |

Deliverables: KPI dashboard, Final report, 6-month development plan

### Page 13: Final Deliverables (table)
10 numbered deliverables with descriptions

### Page 14: KPIs (table)
| Indicator | Current State | Target |
|-----------|--------------|--------|
| Website pages completed | Incomplete | All active |
| Articles published | ~0 | 12+ |
| Content produced | Reposting | 40+ original |
| LinkedIn completed | None | Active page |

### Page 15: Execution Method
6-step cycle: Analysis → Design → Approval → Execution → Measurement → Improvement

### Page 16: Roles & Responsibilities (2 columns)
| Consultant Commitments | Client Commitments |
|----------------------|-------------------|
| Strategy development | Content approval |
| Content execution | Project information |
| Data analysis | Weekly meetings |
| Team training | Platform access |

### Page 17: Project Risks (table)
| Risk | Probability | Solution |
|------|------------|----------|
| Content approval delays | High | Weekly meeting + 24h deadline |
| Missing project info | Medium | Designate info contact |

### Page 18: Client Prerequisites
- Website admin access
- Social media access
- High-quality project photos
- Technical project information

### Page 19: Conclusion
"These three months are the beginning of a media system, not a one-time project."

## Key Differentiators from Basic Proposals
1. **Data-driven approach** — mention data mining as expertise
2. **Consulting-level structure** — not just Instagram posts
3. **Risk assessment** — shows professionalism
4. **RACI/responsibilities** — clear accountability
5. **KPIs tied to deliverables** — measurable outcomes
6. **Phase-by-phase with weekly breakdown** — shows operational thinking
7. **Future-oriented** — mentions 6-month development plan
